## Reproducing the processed data

1. **Get the full dataset** (not just the Week 4 sample, which only has
   git-annex pointer files for the binary EEG data -- see `DataAnalysis.md`
   Limitation 5.1). From the repo root:
   ```bash
   pip install awscli
   mkdir ds004902
   aws s3 sync --no-sign-request s3://openneuro.org/ds004902 ./ds004902
   ```
   This downloads ~8.3 GB and is already covered by `.gitignore` (`/ds004902`
   is never committed).

2. **Install dependencies** (adds `pymatreader`, needed by MNE to read these
   MATLAB v7.3 `.set` files, versus the base `requirements.txt` from Week 4):
   ```bash
   pip install -r requirements.txt
   ```

3. **Open and run the 5 notebooks in `code/`, in numeric order** (Jupyter /
   VS Code / JupyterLab, same workflow as `deliveries/week04/EDA.ipynb`):
   ```
   01_behavioral_pipeline.ipynb   # cleans participants.tsv -> behavioral_deltas.csv
   02_eeg_pipeline.ipynb          # ~15-20 min for all 218 recordings -- see LIMIT below
   03_merge_pipeline.ipynb        # joins 01 + 02 -> merged_summary.csv
   05_findings_plots.ipynb        # real charts (real data) -> analysis_plots/
   ```
   `01` and `02` are independent of each other and can run in any order; `03`
   requires both of their outputs in `data/processed/` first; `05` requires
   `01`-`03` to have run first. (`04_make_sketches.ipynb` also exists in
   `code/` as a wireframe generator, but its output is not part of this
   delivery -- see "Where is everything" above.)

   `02_eeg_pipeline.ipynb` auto-detects `../../../ds004902` (repo root); if
   it isn't there yet, it falls back to the Week 4 sample (`sub-01` only, and
   note that the committed sample's `.set`/`.fdt` are git-annex pointers, so
   that fallback path will currently produce zero usable recordings until the
   real sample bytes are fetched too). To iterate quickly instead of waiting
   ~15-20 min, set the `LIMIT` variable near the top of the notebook to a
   small number (e.g. `4`) before running the rest of the cells, then set it
   back to `None` for the real, full-dataset run before trusting the output.
