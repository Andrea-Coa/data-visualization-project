# Paper: borrador inicial (Semana 12)

`FinalPaper_draft.html` (con `paper.css`) es la fuente editable del borrador, en HTML y CSS que imitan el formato de dos columnas de IEEE VIS; el resumen gráfico (Fig. 1) y la curva de especificación (Fig. 3, dibujada desde `app/data/multiverse.json`) son SVG en línea, y la Fig. 2 es la captura `dashboard-1365x768.png` copiada de `../assets/`.
`FinalPaper_draft.pdf` se imprimió desde ese HTML con Chrome sin cabecera (tamaño carta); `fig1-resumen-grafico.svg` y `fig3-multiverso.svg` son copias sueltas de las dos figuras vectoriales.
Las cifras salen de `../research/hechos_clave.md` y las referencias de `../research/literatura_verificada.md` (y de `informe_conectividad.md` para la conectividad).
La versión final se portará a la plantilla LaTeX de IEEE VIS (Overleaf) en la Semana 14.
